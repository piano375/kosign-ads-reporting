# Dashboard behavior

The landing view has exactly two primary cards: Cost per Acceptance and Acceptances for the same rolling last seven complete account-timezone days. Both are marked provisional because Acceptance is manually staged and may backfill.

The four performance charts use complete Monday through Sunday periods. The funnel chart keeps its mature weekly line separate from the current seven-day period and includes a mature-period median. Missing required events are unavailable rather than zero. All chart values have a visible table alternative.

The page is read-only. It does not alter campaigns, budgets, audiences, ads, or account settings.
